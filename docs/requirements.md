
# E-Commerce DevOps Platform

## Objective
Build a secure, repeatable delivery platform for a
containerized e-commerce application.

## Application requirements
- Product catalogue
- Backend REST API
- Shopping cart and order functionality
- Database integration
- Automated tests and health checks

## DevOps requirements
- Git and GitHub
- Docker
- Jenkins CI pipeline
- Automated testing and security scanning
- Terraform infrastructure as code
- AWS infrastructure and container registry
- Kubernetes and Helm
- Argo CD GitOps
- Prometheus and Grafana monitoring
- Rollback and troubleshooting documentation

## Security and cost
- Never commit secrets or credentials.
- Use least-privilege access.
- Monitor cloud spending and clean up unused resources.
